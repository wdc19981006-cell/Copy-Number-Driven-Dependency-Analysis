Copy Number–Driven Dependency Analysis
==================================================

Gene A: MTAP
Gene B: WDR77
TCGA: Current TCGA dataset
DepMap: Public 26Q1
Run date: 2026-10-18 17:16:05 CST
DATA_MODE: local（仅读取本地 processed 数据）
TCGA 主结果使用本地已验证的 current TCGA 数据；Source / release 信息见 Provenance。
五级 CNA 基于 current gene-level CN 与 sample-specific baseline/ploidy，是 analysis-defined 分类，不是官方 GISTIC 五级值。
baseline 使用每个样本常染色体 gene-level CN 的整数众数估算；不是直接测量的 ploidy。
DepMap 为用户提供的 26Q1 导出文件；相对官方完整 release 的完整性未验证。
CN-low: log2(relative CN + 1) < 0.585；分析定义，不是五级 GISTIC。

==================================================
Key Findings
==================================================
- MTAP deletion 比例最高的癌种：SKCM 70.6%；GBM 70%；LUSC 64.1%
- CN-mRNA：33 癌种图；29 癌种 Pearson BH-FDR < 0.05。
- WDR77 Eligible_Rank：3
- CN-low N=234；CN-normal N=624。
- median Chronos：low -1.56；normal -1.2803；Delta -0.27975。
- Wilcoxon P <2e-16；CN_log Pearson r 0.3177；Spearman rho 0.232。
- 同方向且 FDR < 0.05 的 lineage：Pancreas、Peripheral Nervous System、CNS/Brain、Ovary/Fallopian Tube、Breast、Lymphoid、Myeloid、Lung
- 以上为观察性相关与依赖差异，不能解释为 CN 缺失导致 dependency 或其他基因 CN 改变。
